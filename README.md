# TradeEase — Trading App Usability Redesign

**Assessment 3 | UI/UX Design | Usability Evaluation | Figma**

## Project Overview

TradeEase is a collaborative academic project focused on redesigning a mobile trading application's user interface to improve usability, transparency, and accessibility.

Building on the issues identified in Assessment 2, this project focuses on helping users understand transaction fees, navigate automatic investing, and complete common financial tasks with greater clarity. The proposed solution is a high-fidelity Figma prototype designed around user-centred design principles.

**Project status:** Design and prototyping in progress.

## Project Objectives

- Improve transaction fee transparency before users confirm an order.
- Simplify automatic investing through a guided, step-by-step workflow.
- Make buying assets and transferring funds easier to understand.
- Provide accessible help through an in-app chatbot concept.
- Evaluate the redesigned interface through usability testing.

## Key Features

### 1. Home Dashboard

A simplified overview of the user's portfolio, balance, assets, and key actions.

### 2. Asset Search and Trading

A streamlined workflow for finding assets, entering an investment amount, reviewing an order, and viewing a simulated confirmation.

### 3. Transparent Fee Breakdown

A clear summary of the asset cost, brokerage fee, estimated spread, and total estimated cost before order confirmation.

### 4. Automatic Investing

A guided setup process that helps users select an asset, enter an amount, choose an investment schedule, and review their plan.

### 5. Fund Transfers

A simplified interface for entering a transfer amount, reviewing transfer details, and viewing a simulated confirmation.

### 6. Help Chatbot

A chatbot concept that explains transaction fees and helps users understand common trading tasks in plain language.

## Design Process

The project follows a user-centred design approach:

1. **Analyse:** Review usability issues identified in Assessment 2.
2. **Identify:** Prioritise the main user pain points.
3. **Design:** Create wireframes and improved interface layouts.
4. **Prototype:** Develop high-fidelity screens and an interactive Figma prototype.
5. **Evaluate:** Conduct usability testing with participants.
6. **Refine:** Use findings to identify further improvements.
